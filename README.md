# Christian Gutierrez — Portfolio

Portafolio personal inspirado en la estructura editorial y de portfolio de Yan Holtz, pero con identidad, contenido y proyectos propios.

## Stack
- React
- Vite
- Lucide React
- CSS responsive

## Ejecutar

```bash
npm install
npm run dev
```

## Personalizar
1. Reemplaza el email de `src/main.jsx`.
2. Añade tus URLs reales de LinkedIn y GitHub.
3. Sustituye los visuales placeholder de proyectos por capturas reales de Power BI, FactuOnLine y otros proyectos.
4. Añade enlaces reales a cada proyecto cuando estén publicados.
